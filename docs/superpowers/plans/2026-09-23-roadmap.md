# Diamond Vending — Implementation Roadmap

**Spec:** [`docs/superpowers/specs/2026-09-23-diamond-vending-design.md`](../specs/2026-09-23-diamond-vending-design.md)

The spec is one mod, but most of it depends on exact Minecraft/loader APIs for two game versions
(1.21.1 and 26.1.2). Writing every task's code up front would mean guessing API signatures.
Instead the work is split into **five plans, each producing working, tested software**. Plan 1
is written in full now. Each later plan is written **after the previous one merges**, when the
decompiled Minecraft sources for both versions are on disk and every signature can be checked.

| Plan | Delivers | Testable result | Status |
|---|---|---|---|
| **1 — Foundation** ([plan](2026-09-23-plan-1-foundation.md)) | JDK + Stonecutter project for {1.21.1, 26.1.2} × {Fabric, NeoForge}; mod entrypoints/metadata; CI + Dependabot; pure-Java core logic: click regions (`MachineLayout`), purchase decisions (`PurchaseRules`), problem detection (`MachineProblems`) | 4 jars build in CI; core unit tests green | Done |
| **2 — The machine** | Loader `Platform` abstraction + registration; 2×2 multiblock block (facing/half/side/color states, light 6, blast 1200, no pistons, wither/dragon immune); master block entity with owner; placement checks; break-all; owner/admin-only breaking & dyeing; machine item carrying color; art generator for models/textures/icon; machine recipe; GameTest harness on all 4 targets | Place, dye, and break a protected machine in-game; GameTests green | Not written |
| **3 — Buying** | Selections (template + price) with save/sync; front-face click routing via `MachineLayout`; purchase transaction via `PurchaseRules`; per-player credit + coin return; 9-slot tray; problems via `MachineProblems`; renderer for shelf items, price tags, LED display (red scrolling problems), blinking lamp, tray contents, drop animation; hover HUD; per-click action-bar messages; vanilla sounds; owner sneak-with-item hint | Stock a machine by command/NBT and buy from it; GameTests green | Not written |
| **4 — Running a shop** | Tabbed setup screen (Selections, Stock, Cash Box, Admin) with ghost slots, quantity/price editing, withdraw, problem banner and tab "!"; validated payloads; infinite toggle (requires empty stock/cash); currency slot + currency resolution; datapack catalogs (reload listener, codec, example catalog, `docs/catalogs.md`); setup kept on the item; infinite kept only for admin placers | Full owner and admin flows in-game; GameTests green | Not written |
| **5 — Manual, polish & v1.0** | "New Franchise Owner" written-book manual covering every rule; manual recipe; lang-completeness test; art polish; manual QA checklist run on all 4 jars + a dedicated server; CHANGELOG; v1.0.0 GitHub release with jars | Release published to the repo | Not written |

Each plan runs on its own branch (`plan-N/<name>`), merges via PR after CI is green, and closes
with a short entry in `CHANGELOG.md`.
